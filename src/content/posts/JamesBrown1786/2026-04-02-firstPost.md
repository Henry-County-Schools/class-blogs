Git hub commands can get confusing. I’ll walk you through on how to you can remember the steps. First thing is you got to remember the word “git” that will always be there when writing a git command. The second thing is knowing what your gitting. For example, like committing or adding a file. The third thing is you need to know what the commands mean: “Commit” means to save your progress, “Add” means to create/add a new or existing file to a directory, “Staus” mean to display the current directory your working on, ect… Hopefully this will help you remember the git commands, and remember don’t forget to GIT COMMIT.
